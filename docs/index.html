Helios Frame Kullanım Kılavuzu

Derleme adımı ve Node.js gerektirmeyen, paylaşımlı hosting'de çalışan Vanilla JS (ES6+) ön yüz çatısı. Bu kılavuz kurulumdan yeni sayfa eklemeye kadar tüm temel konuları örneklerle anlatır.

1. Hızlı başlangıç

Proje tamamen statik dosyalardan oluşur. Tek giriş noktası index.html dosyasıdır ve uygulama <script type="module"> ile başlar.

Yerelde çalıştırma

ES modülleri file:// ile (dosyaya çift tıklayarak) çalışmaz. Basit bir statik sunucu yeterlidir:

terminal
python3 -m http.server 8080
# veya
npx serve

# tarayıcı: http://localhost:8080

Demo sayfalar

AdresNe gösterir
/#/Ana sayfa
/#/shopE-ticaret: ürün listesi, sepet, ödeme
/#/b2bB2B panel (giriş: herhangi bir e-posta + parola demo)

Varsayılan olarak veriler data/*.json dosyalarından ve localStorage'dan gelir (mock mod). Arka uç (backend) gerekmez.

Test (yalnızca geliştirme)

terminal
npm install
npm test

Test, uygulamayı jsdom içinde başlatıp ana akışları (liste, sepet, ödeme, yetki kontrolü, tablo, grafik, teklif formu) gezer. Canlı sitede Node.js gerekmez.

4. Router

Rota tanımı

Rotalar src/routes.js içinde tanımlanır. Sayfalar import() ile tembel yüklenir, yani yalnızca ziyaret edilince indirilir.

src/routes.js
export const routes = [
  { path: '/', component: () => import('./pages/home.page.js'), layout: 'default', meta: { title: 'Ana Sayfa' } },

  // Parametreli yol: /shop/helios-kablosuz-kulaklik -> params.slug
  { path: '/shop/:slug', component: () => import('./pages/shop/detail.page.js'), layout: 'shop' },

  // Giriş gerektiren sayfa
  { path: '/b2b/customers', component: () => import('./pages/b2b/customers.page.js'),
    layout: 'b2b', meta: { title: 'Müşteriler', auth: true } },

  // Yönlendirme
  { path: '/b2b', redirect: '/b2b/dashboard' },

  // Joker: en sona koyun, 404 sayfası olur
  { path: '*', component: () => import('./pages/not-found.page.js'), layout: 'default' },
];

Sıra önemlidir. İlk eşleşen rota kazanır. /shop/cart gibi özel yolları /shop/:slug gibi parametreli yollardan önce yazın.

AlanAçıklama

componentSınıf ya da () => import(...) (modülün default export'u kullanılır).
layoutlayouts içindeki anahtar: default, shop, b2b, blank.
meta.titleSekme başlığı. Metin ya da (to) => metin olabilir.

// /shop/helios-kablosuz-kulaklik?ref=mail

Bağlantı ve yönlendirme

// Bağlantı: href() hash/history moduna göre doğru adresi üretir
html`<a href="${this.href('/shop/cart')}">Sepet</a>`

// Koddan yönlendirme

Bağlantıları elle #/shop diye yazmayın, her zaman this.href() kullanın. Böylece router modunu değiştirdiğinizde hiçbir şey bozulmaz.

Yetki kontrolü (guard)

Guard'lar src/app.js içinde tanımlanır. true devam, false iptal, metin ise o yola yönlendirme demektir.

router.beforeEach((to, from) => {
  const user = store.state.user;
  if (to.meta.auth && !user) return `/login?next=${encodeURIComponent(to.path)}`;
  if (to.path === '/login' && user) return '/b2b/dashboard';
  return true;
});

İstemci tarafı guard yalnızca arayüz akışıdır, güvenlik sağlamaz. Gerçek yetkilendirme sunucuda yapılmalıdır.

5. Component

Her sayfa ve bileşen Component sınıfından türer. Çatı, olayları, abonelikleri ve iptal sinyallerini bileşen yok olunca otomatik temizler.

Yaşam döngüsü

constructor(props, ctx)
  -> static libs yüklenir
  -> beforeMount()     Host DOM'da, içerik yok. Olay/abonelik kurulumu burada.
  -> render()          html`` döndürür
  -> afterRender()     HER render sonrası. Alt bileşen / 3. parti widget burada.
  -> afterMount()      Yalnızca ilk render sonrası. Veri yükleme burada.

setState(patch)
  -> shouldUpdate(next, prev)  false ise çizim atlanır
  -> render() -> afterRender()

destroy()
  -> beforeUnmount()   Elle temizlik gerektiren şeyler (Chart.destroy gibi)
  -> iptal sinyali, alt bileşenler, dinleyiciler ve abonelikler otomatik temizlenir

Örnek: veri yükleyen sayfa

src/pages/example.page.js
import { Component } from '../core/component.js';
import { html } from '../core/dom.js';

export default class ExamplePage extends Component {
  state = { loading: true, error: null, items: [] };

  async afterMount() {
    try {
      const res = await this.ctx.services.products.list({ perPage: 4, signal: this.signal });
      this.setState({ items: res.items, loading: false });
    } catch (err) {
      if (err.name === 'AbortError') return;   // sayfa terk edildi, sorun değil
      this.setState({ error: err.message, loading: false });
    }
  }

  render() {
    const { loading, error, items } = this.state;
    if (loading) return html`<p>Yükleniyor…</p>`;
    if (error) return html`<div class="alert alert-danger">${error}</div>`;
    return html`
      <h1>Ürünler</h1>
      <ul>${items.map((p) => html`<li>${p.name}</li>`)}</ul>`;
  }
}

State (durum)

Her bileşenin kendi yerel durumu this.state içindedir. Değiştirmek için setState kullanılır, doğrudan atama yapılmaz.

this.setState({ loading: true });                       // nesne ile
this.setState((prev) => ({ count: prev.count + 1 }));   // önceki duruma göre
this.update();                                          // state değişmeden yeniden çiz

HTML şablonu ve güvenlik

html`` içine yerleştirilen her değer otomatik escape edilir (XSS koruması). İç içe html`` sonuçları ve diziler olduğu gibi birleştirilir.

import { html, raw } from '../core/dom.js';

const isim = '<script>alert(1)</script>';
html`<p>${isim}</p>`;                  // güvenli: metin olarak gösterilir
html`<ul>${[1, 2].map((n) => html`<li>${n}</li>`)}</ul>`;   // dizi birleştirilir
html`<div>${raw('<b>kalın</b>')}</div>`;       // escape EDİLMEZ: yalnızca kendi ürettiğiniz içerik için

render() düz bir metin döndürürse HTML olarak yorumlanır. Kullanıcı verisini asla düz metin birleştirerek basmayın, daima html`` kullanın.

Olaylar

this.on() olayı bileşenin kök elementi üzerinde delege eder. Yeniden çizimlerden sonra tekrar kurmanız gerekmez ve bileşen yok olunca otomatik silinir.

beforeMount() {
  this.on('click', '[data-add]', (e, el) => {
    const id = Number(el.dataset.add);          // el: tıklanan [data-add] elementi
    addItem(this.ctx.store, this.state.items.find((p) => p.id === id));
  });
  this.on('input', '[name=q]', (e, el) => this.search(el.value));
  this.on('submit', 'form', (e) => { e.preventDefault(); this.save(); });

  this.listen(window, 'resize', () => this.measure());   // document/window olayları
}

Abonelikler ve temizlik

// Store aboneliği: yalnızca seçilen değer değişince çalışır
this.watch(this.ctx.store, (s) => s.cart, () => this.update());

// Olay yolu (bus)
this.onBus('route:change', (to) => this.setState({ path: to.path }));

// Kendi temizlik işiniz (zamanlayıcı vb.)
const t = setInterval(() => this.tick(), 1000);
this.addCleanup(() => clearInterval(t));

İptal sinyali

this.signal bileşen yok olunca iptal edilir. İstekte kullanırsanız kullanıcı sayfadan ayrıldığında yarım kalan istek de iptal olur.

await this.ctx.services.http.get('/products', { signal: this.signal });

Alt bileşenler

Alt bileşenleri afterRender() içinde mountChild() ile bağlayın. Ebeveyn yeniden çizilince alt bileşenler yok edilip yeniden kurulur.

render() {
  return html`${this.state.items.map((p) => html`<div data-product="${p.id}"></div>`)}`;
}

afterRender() {
  const byId = new Map(this.state.items.map((p) => [String(p.id), p]));
  this.$$('[data-product]').forEach((slot) => {
    this.mountChild(ProductCard, slot, { product: byId.get(slot.dataset.product) });
  });
}

Alt bileşen ebeveyn içinde yeniden kurulduğunda kendi state'i sıfırlanır. Korunması gereken veriyi ebeveynin state'ine ya da store'a koyun.

Yazarken yeniden çizim

Her setState bileşenin içeriğini yeniden kurar. Çok yazılan formlarda bu istenmez. Çözüm: değerleri state yerine sıradan bir alanda tutun (örnek: quote-form.page.js ve checkout.page.js).

values = { company: '', email: '' };          // state DEĞİL, yeniden çizimi tetiklemez

beforeMount() {
  this.on('input', '[name]', (e, el) => { this.values[el.name] = el.value; });
}

Ayrıca yeniden çizimde id, data-key veya name özniteliği olan input'un odağı ve imleç konumu otomatik geri yüklenir.

6. Layout

Layout, sayfalar arasında kalıcı olan kabuktur (üst menü, yan menü, alt bilgi). Sayfa, layout içindeki data-outlet elementine yerleşir. Sayfa değişirken layout aynı kalırsa yeniden kurulmaz.

src/layouts/shop.layout.js
import { Layout } from '../core/layout.js';
import { html } from '../core/dom.js';
import { ShopHeader } from '../components/shop-header.js';

export default class ShopLayout extends Layout {
  render() {
    return html`
      <div data-slot="header"></div>
      <main data-outlet class="container py-4"></main>      <!-- sayfa buraya gelir -->
      <footer>© ${this.ctx.config.brand}</footer>`;
  }

  afterRender() {
    this.mountChild(ShopHeader, '[data-slot=header]');   // dinamik parça: alt bileşen
  }
}

Önemli: Layout kendi içinde setState / update çağırmamalıdır, aksi halde sayfanın yerleştiği alan silinir. Sepet rozeti gibi değişen parçaları alt bileşen yapın (ShopHeader örneği).

Yeni layout eklemek için dosyayı oluşturup routes.js içindeki layouts nesnesine kaydedin:

export const layouts = {
  // ...
  admin: () => import('./layouts/admin.layout.js'),
};
// rota: { path: '/admin', component: ..., layout: 'admin' }

7. Store (durum yönetimi)

Uygulama genelinde paylaşılan durum için küçük bir store vardır. Durum değişmez (immutable) kabul edilir: nesneleri yerinde değiştirmeyin, yenisini üretip verin.

const store = this.ctx.store;

store.state.user                                  // okuma
store.set({ user: null });                        // kısmi güncelleme
store.set((s) => ({ cart: { ...s.cart, items } })) // önceki duruma göre

// Abonelik: dönen fonksiyon aboneliği iptal eder
const stop = store.subscribe((count) => console.log(count), (s) => s.cart.items.length);

Bileşen içinde this.watch() kullanırsanız abonelik otomatik iptal edilir.

Kalıcılık (localStorage)

src/app.js içinde hangi anahtarların saklanacağı belirlenir. Sekmeler arası senkron storage olayıyla otomatik yapılır.

src/app.js
const store = new Store(initialState, {
  persistKey: `${config.storage.prefix}app`,
  persistKeys: ['cart', 'user', 'prefs'],   // yalnızca bunlar kaydedilir
  version: 1,                                // değişirse eski kayıtlar atılır
});

Durum yapısını değiştirdiğinizde (ör. sepet öğelerine yeni alan) version değerini arttırın. Böylece kullanıcıların tarayıcısındaki eski biçimli veriler sorun çıkarmaz.

Yeni durum alanı ekleme

// 1) src/store/state.js

export function toggleFavorite(store, id) {
  store.set((s) => ({
    favorites: s.favorites.includes(id) ? s.favorites.filter((x) => x !== id) : [...s.favorites, id],
  }));
}

9. Harici kütüphaneler

Şu an projede hiçbir JavaScript kütüphanesi yoktur. Tablo ve grafik bileşenleri kütüphanesiz yazılmıştır. Yalnızca UI çatısının (Bootstrap) CSS dosyası yüklenir, JavaScript'i yüklenmez.

Bir kütüphane gerektiğinde, Next.js'te olduğu gibi ihtiyaç duyulan yerde açıkça referans verilir. Derleyici olmadığı için npm install yerine CDN adresi ya da vendor/ klasöründeki dosya kullanılır.

Next.js'teHelios Frame'de
<Script src="..." strategy="lazyOnload" /> (sayfada)Sayfa/bileşende static libs = [{ global, js: [...] }]
_app / _document içinde genel scriptconfig.js → globalLibs ya da index.html'e <script defer src>
import x from 'paket'import x from 'https://cdn.jsdelivr.net/npm/paket@1/+esm' (ES modülü) veya import x from '../../vendor/x.js'
Paketi kendi sunucundan servis etmekDosyayı vendor/ altına koyup yolunu vermek

1) Sayfada/bileşende referans (önerilen)

Kütüphane yalnızca bu sayfa açılınca, ilk çizimden önce yüklenir. Başka sayfalar etkilenmez.

  beforeUnmount() {
    this.chart?.destroy();           // sayfadan çıkarken kütüphane nesnesini temizle
  }
}

Tam örnek: iletişim formu

src/pages/contact.page.js
import { Component } from '../core/component.js';
import { html } from '../core/dom.js';
import { validate, minLength } from '../core/forms.js';
import { formField } from '../ui/form-field.js';

export default class ContactPage extends Component {
  state = { errors: {} };
  values = { name: '', email: '', message: '' };      // state değil: yazarken yeniden çizim olmaz

  beforeMount() {
    this.on('input', '[name]', (e, el) => { this.values[el.name] = el.value; });
    this.on('submit', 'form', (e) => {
      e.preventDefault();
      const errors = validate(this.values, {
        name: ['required', minLength(3)],
        email: ['required', 'email'],
        message: ['required', minLength(10)],
      });
      this.setState({ errors });                       // hata varsa kutular kırmızı olur
      if (!Object.keys(errors).length) this.ctx.toast.success('Mesajınız alındı');
    });
  }

  render() {
    const { errors } = this.state;
    const v = this.values;
    return html`
      <h1>İletişim</h1>
      <form class="row g-3" novalidate>
        ${formField({ name: 'name', label: 'Ad soyad', value: v.name, error: errors.name, col: 'col-md-6' })}
        ${formField({ name: 'email', label: 'E-posta', type: 'email', value: v.email, error: errors.email, col: 'col-md-6' })}
        ${formField({ name: 'message', label: 'Mesaj', type: 'textarea', value: v.message, error: errors.message })}
        <div class="col-12"><button class="btn btn-primary">Gönder</button></div>
      </form>`;
  }
}

import { Component } from '../core/component.js';

export default class BlogPage extends Component {
  state = { loading: true, error: null, posts: [] };

  async afterMount() {
    try {

      this.setState({ posts, loading: false });

        <article class="card mb-3"><div class="card-body">
          <h2 class="h5">${p.title}</h2><p class="mb-0 text-body-secondary">${p.summary}</p>
        </div></article>`)}`;
  }
}

14. Yayına alma (GoDaddy / paylaşımlı hosting)

  1. cPanel → Dosya Yöneticisi ya da FTP ile projeyi public_html altına yükleyin. node_modules ve tests klasörleri gerekmez.
  2. Varsayılan hash modunda başka ayar gerekmez. Adres: https://siteniz.com/#/shop.
  3. Temiz adres (/shop) isterseniz config.js içinde router.mode: 'history' yapın. .htaccess içindeki yönlendirme kuralı hazırdır.
  4. Alt klasöre (/magaza/) yüklerseniz .htaccess içindeki RewriteBase değerini /magaza/ yapın.
  5. Sitenizde HTTPS kullanın (CDN kaynakları ve güvenlik için).

Dosyalar derlenmediği için JS/CSS adları değişmez. Yeni sürüm yüklediğinizde eski sürümün tarayıcı önbelleğinde kalmaması için .htaccess içinde önbellek süresi kısa tutulmuştur (JS/CSS için 1 saat). Acil güncellemede tarayıcıda Ctrl+F5 yapın.

Güvenlik başlığı: Canlıda bir Content-Security-Policy tanımlamanız önerilir. Bootstrap CSS'i ya da kendi eklediğiniz kütüphaneler için CDN kullanıyorsanız ilgili alan adlarını (örn. cdn.jsdelivr.net) izin listesine ekleyin. Hiç dış bağlantı istemiyorsanız dosyaları vendor/ altına koyup libMode: 'local' kullanın.

15. Sorun giderme

BelirtiNeden / çözüm
Sayfa boş, konsolda CORS veya "module" hatasıindex.html dosyasını çift tıklayarak açtınız. Bir sunucu üzerinden açın (python3 -m http.server).
